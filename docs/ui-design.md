# 番仓 AniVault UI 设计规范（0.8.0）

> 历史基线：这里保留 0.8.0 的视觉规则与验收依据，示意图中的版本徽标不是当前版本。当前版本由根目录 `VERSION` 与 `renderer/index.html` 同步维护。

## 设计 token

### 颜色（5 个主色）

| Token | Hex | 用途 |
| --- | --- | --- |
| `--color-header` | `#14324A` | 头部深蓝 |
| `--color-primary` | `#0B6E4F` | 主按钮 / 焦点 / 成功 |
| `--color-bg` | `#F4F6F8` | 页面底色 |
| `--color-border` | `#D9E2EC` | 卡片与输入边框 |
| `--color-text` | `#1F2933` | 正文 |

补充：`--color-muted #829AB1`（提示）、`--color-error #B3261E`（错误/运行中）、`--color-log-bg #0F172A` + `--color-log-text #D1FAE5`（终端日志，签名元素）。

### 字体层级

- 头部标题：20px / 600
- 区块标题：15px / 600
- 正文与表单：13px
- 提示与表格：12px
- 日志：12px 等宽（Consolas / Courier New）

### 间距刻度

4 / 8 / 12 / 16 / 24，卡片内边距 12–14，区块间距 16，页面外边距 20。

### 控件

- 输入框、按钮、选择框最小高度 30px，`box-sizing: border-box`。
- 按钮层级：主按钮实底（primary），次按钮白底描边，危险操作同次按钮。
- 键盘焦点：`:focus-visible` 显示 2px 主色描边。

## 布局（ASCII）

```
+------------------------------------------------------------------------+
| 番仓 AniVault                                   [v0.8.0]   [运行状态徽标] |
+------------------+-----------------------------------------------------+
| 全局设置（两列）  | 追番清单                                             |
| 每项高 30px      | 卡片头部：箭头 | 片名 | 启停(开/关) | 删除（垂直居中）|
|                  | 字段三列网格                                          |
+------------------+-----------------------------------------------------+
| 运行控制：按钮行 / 状态徽标 / 每集状态                                  |
| +---------------------------+ +---------------------------------------+ |
| | 日志（等高，各自滚动）     | | 待下载清单（等高，各自滚动）           | |
| +---------------------------+ +---------------------------------------+ |
+------------------------------------------------------------------------+
```

## 规则

- 全局设置两列；追番字段三列；日志与清单等高且各自滚动。
- 卡片头部控件垂直居中、等高 30px。
- 表格操作列固定宽，URL 列允许断行。
- 任何窗口尺寸下页面不出现横向滚动条。
- 启停控件：同一 label 内「勾选框 + 开/关」，勾选=开、取消=关，change 即时切换文字，整块可点。
